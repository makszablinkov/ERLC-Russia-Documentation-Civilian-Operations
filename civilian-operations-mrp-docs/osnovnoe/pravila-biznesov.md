# Правила бизнесов

<h2 align="center">Раздел A — Регистрация бизнеса</h2>

<h2 align="center">Раздел B — Основное положение</h2>

**B-1** — Любой бизнес считается легальным только после одобрения заявки Менеджером Гражданских операций и внесения в онлайн-таблицу  бизнесов.

{% hint style="info" %}
_Для подачи заявки на бизнес нужно оформить 2 заявки:_ [_**Google Forms**_](https://docs.google.com/forms/d/e/1FAIpQLSd_cJ_zD8mhhNMnnh_0pE01DaUXuGeldehvtM4GFNEKctzwdA/viewform?usp=dialog) _заявка и_ [_Discord_ ](#user-content-fn-1)[^1]_заявка_
{% endhint %}

**B-2** — Охрана и ЧОП. Бизнес имеет право нанимать охрану.

* **B-2.1** — Охранники не имеют права носить тяжелое вооружение (винтовки, спецсредства) в открытом виде без лицензии на охранную деятельность.

**B-3** — Взаимодействие с ОПГ. Бизнес может купить крышу у официального ОПГ. Это фиксируется IC-договором и согласием с Менеджером Гражданских операций.

**B-4** — Лимиты: Один игрок может владеть не более чем 2 бизнесами. Передача бизнеса третьим лицам разрешена только через Менеджера Гражданских операций/мэрию.

**B-5** — Активность: Владелец обязан посещать свой бизнес и открывать его для игроков не менее 3 часов в неделю. Иначе бизнес может получить штраф/закрытие.
